PIYUSH

Overall Website & Frontend / System Architecture
Level: Hardest
Main Responsibility: Project introduction, smart session routing, multi-view authentication architecture (login.html), custom MSME account creation, 8-digit password security enforcement, zero-leak identity-verified password reset, enterprise profile engine, and live deployment.

Codebase Locations & Files

index.html Lines 8–16
Smart Session Router: Checks localStorage.getItem("samarth_user_session"). Agar session active hai toh dashboard.html bhejna, warna login.html par redirect karna.
login.html Lines 54–235 & 238–520
Multi-View Enterprise Authentication & User Management:
  • Sign In View (#signin-view): Secure manual credential entry (pre-seeded demo account piyush123 / 8-digit password 12345678, with 1234567 legacy fallback).
  • Create Account View (#register-view): Complete MSME signup flow allowing users to register Full Name, User ID, Enterprise Name, 10-digit Mobile, and minimum 8-digit Password with live validation and persistence in samarth_registered_users.
  • Forgot Password View (#forgot-view): Zero-leak 2-step verification protocol. Step 1 verifies registered User ID + 10-digit Mobile; Step 2 unlocks setting a new 8-digit password without exposing sensitive info publicly.
  • UI Features: Live 8-character password length counter, interactive show/hide password toggles, shake animations on errors, and single sign-on session creation.
dashboard.html Lines 24–56 & 740–762
Central Enterprise Hub: Multi-page unified navigation header connecting schemes.html, profile.html, and expenses.html. Bottom script handles session check & logout handler.
profile.html Lines 90–220
Enterprise Profile Engine: Promoter parameters form, live MSME Readiness Scorecard calculations, and demographic scheme recommendations.
script.js Lines 98–191
Global Utilities & Profile Sync: formatINR() currency formatter, showToast() notification engine, and two-way sync between saved profile savings and fund planner.
Possible Judge Question: "Naya user kaise account banata hai aur forgot password kaise secure hai?"
Answer: 'Create Account' form se naya user apna unique ID, enterprise name aur min 8-digit password register kar sakta hai jo browser ke dynamic user database (samarth_registered_users) me save hota hai. 'Forgot Password' me bina kisi public data leak ke, pehle registered username aur 10-digit mobile verify hota hai, uske baad hi naya 8-digit password set karne ki permission milti hai.
Possible Judge Question: "Website ka data kahan store hota hai?"
Answer: Current prototype browser ke localStorage me client-side session store karta hai taaki bina server setup ke instant chal sake. Production roadmap mein ise cloud PostgreSQL/MongoDB aur secure JWT authentication se replace kiya jayega.

Codebase Locations & Files

Possible Judge Question: "DPR kya hota hai aur Debt-to-Equity ratio kya batata hai?"
Answer: DPR (Detailed Project Report) bank loan approval ke liye project ki financial feasibility file hai. Debt-to-Equity ratio yeh batata hai ki promoter ke ₹1 ke mukable bank ka kitna loan laga hai. MSME norms ke anusar 2:1 se 3:1 ideal maana jata hai.
